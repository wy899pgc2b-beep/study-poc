# 技術検証用の試作品(ブラウザ版)

学習態度AI評価アプリの技術検証(フェーズ0)で使う試作品です。iPhone の Safari で開くだけで、アプリをインストールせずに AI の判定を試せます。

**確かめること**

| 確かめること | 方法 |
| --- | --- |
| 下を向いて読んでいるときに、居眠りと誤判定しないか | 検証シナリオの「教材を読む」 |
| 居眠り・よそ見・離席・癖を検知できるか | 検証シナリオの各場面 |
| 目と机の距離を推定できるか | 検証シナリオの「顔を机に近づける」、画面の「目と机の距離」 |
| iPhone で処理が間に合うか、電池がどのくらい減るか | 「自由に学習」で 30 分以上使い、結果画面を見る |

映像は iPhone の中だけで処理し、保存もサーバーへの送信もしません。通信するのは、AI ライブラリとモデルのダウンロード(初回のみ・約 34MB)だけです。

## iPhone で開く

iPhone の Safari で次のページを開いてください。

**https://wy899pgc2b-beep.github.io/study-poc/**

## 使い方

1. iPhone を充電しながら、スタンドに立てて机の奥に置く。
2. 「設定」アプリ → 画面表示と明るさ → 自動ロック を「なし」にする(Safari が画面の消灯を止められない場合に備えて)。
3. ページを開き、「検証の種類」を選んで「カメラを起動する」を押す。カメラ・動きセンサーの許可を求められたら「許可」を選ぶ。
4. 音声の案内に従って位置を合わせる。顔と肩が映ると自動で「キャリブレーション」に進む。正しい姿勢で教材を 3 秒見た後、**そのまま 3 秒目を閉じる**(音が鳴ったら開ける)。目を閉じたときの値は、カメラ・置き方・メガネで変わるため、毎回記録する(今は判定には使わず、分析用に記録するだけ)。
5. **検証シナリオ**:音声の指示(読む → 書く → 目を閉じる(顔は上げたまま) → 前に傾いて目を閉じる(いつもの居眠りの姿勢) → 机に伏せる → よそ見 → 顔や頭を触る → 顔を近づける → 離席)に従う。各場面の終わりに「ピッ」と鳴る。約 4 分半で自動的に結果が出る。キャリブレーション(正しい姿勢で教材を見る 3 秒間)の間は手を止める。
6. **自由に学習**:普段どおり学習し、終わったら「終了」を押す。
7. 結果画面の「データをコピー」で、数値の記録(映像は含まない)を JSON で取り出せる。設定画面の下に「試作品の版」が出る。公開の直後は古い版がキャッシュから読み込まれることがあり、そのときは警告が出るので、数分待って再読み込みする。**この JSON を送ってもらえれば、しきい値の調整に使います。** 「自由に学習」では、警告(うとうと・居眠り・癖など)の直前 12 秒の様子も入る。

バックカメラでは画面が見えないので、音声を聞き取れる音量にしてください。消音モード(本体の横のスイッチ)がオンだと音が出ない場合があります。

## 置き方

| 置き方 | 置き方の例 | 得意なこと | 苦手なこと |
| --- | --- | --- | --- |
| 正面に立てる | スタンドに立て、机の奥に置く | 書く動作(学習スタイル)、机に伏せる | 前に傾いた居眠り |
| 斜め置き | スタンドを大きく寝かせる、または本などに立てかけて約 45° にする | 前に傾いた居眠り(平置きほど確実ではない) | 書く動作(縦向きでは手元がほとんど映らない) |
| **横向きに立てかける**(おすすめ・検証中) | 横向きにして、本などに少し後ろに傾けて立てかける(10〜25°。30° では手元が映らなかった) | 前に傾いた居眠り、書く動作(両方できた。7・9 回目) | メガネを掛けていると、前に傾いた居眠りを判定できないことがある(8 回目) |
| 平置き | 画面を上にして机に置く | 前に傾いた居眠り、目と机の距離 | 書く動作(手元が映らない) |

**横向きに立てかけるときの手順**:設定で置き方を「横向きに立てかける」、カメラを「フロントカメラ」にする。**iPhone の「画面の向きのロック」を解除してから**、スマホを横向きにして立てかける(ロックがかかっていると映像が横向きにならない。位置合わせの画面に「映像の向き」と「スマホの傾き」が表示される)。フロントカメラが机に近い低い位置に来るので、うつむいた顔と手元の両方が映る。

**斜め置きの手順**:設定で置き方を「斜め置き」、カメラを「フロントカメラ」にする。位置合わせの画面に「スマホの傾き」が表示されるので、35〜55° になるように寝かせる(外れていると音声で知らせる)。顔と手元の両方が映る位置を探す。

## うまく動かないとき

| 症状 | 対処 |
| --- | --- |
| 「カメラの使用が許可されませんでした」 | 設定アプリ → Safari → カメラ → 「許可」 |
| 読み込みが終わらない・動作が止まる | 詳しい設定の「GPU を使う」をオフにして試す |
| 処理速度が 300ms を超える | 詳しい設定の解析の頻度を「2 回/秒」にする |
| 音声が出ない | 消音モードを解除し、音量を上げる |

## しきい値の調整

判定のしきい値は `js/config.js` にまとめてあります(居眠りと判定する秒数、目と机の距離の警告値など)。検証の結果を見て、ここを調整します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html`、`style.css` | 画面 |
| `js/app.js` | 画面の流れ、カメラ、ループ、通知 |
| `js/vision.js` | MediaPipe(顔・手・上半身の特徴点、髪と顔の肌の領域分け)の読み込みと実行 |
| `js/analysis.js` | 判定ロジック(状態、居眠り、癖、姿勢、離席、集中度)。設計書 4 章に対応 |
| `js/scenario.js` | 検証シナリオの場面と、合否の判定 |
| `js/diagnostics.js` | 「自由に学習」の記録(状態ごとの数値の分布、警告の直前の様子) |
| `js/result.js` | 結果画面(集中度のグラフなど) |
| `js/voice.js` | 音声の読み上げとアラーム |
| `js/config.js` | しきい値 |
| `test/` | 判定ロジックのテスト |

## テスト

判定ロジックのテストは Node.js 20 以上で実行できます(追加のインストールは不要)。

```sh
npm test
```

## 分かっている制限

- 「手いじり」「体を揺らす」の検出は、この試作品には入っていません(設計書 4.7)。
- 「書く」は、机の上の手の速さで判定する仮の方法です。手の形(ペンを持つ形)は、手を組んだときと区別できなかったため記録だけにしています。横向きに立てかけると、手がカメラに近く大きく映るため、ペンを持っているだけでも「書く」と判定されることがあります(調整中)。
- 視線の向き・あくび(口の開き)は記録だけしています。判定や通知には使いません。
- うつむき具合は、肩に対する頭の高さと、頭頂部の見える割合(髪 ÷ 髪と顔の肌。画像の領域分けで求める)で判定します。
- 目と机の距離は、正面に立てた場合はカメラが水平に向いている前提で計算しています。スタンドで大きく傾けている場合は誤差が大きくなります。
- ブラウザ版なので、本番の iPhone アプリ(Swift)より処理が遅く、電池の消費も多めに出る可能性があります。
